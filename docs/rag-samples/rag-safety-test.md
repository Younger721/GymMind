# 星河健身房训练区安全与紧急处理规范

## 训练前

1. 新会员首次使用自由重量区前，应先完成器械和安全须知培训。
2. 每次训练前至少进行 8 分钟热身，热身内容包括低强度有氧和目标关节活动。
3. 有伤病史、正在服药或近期做过手术的会员，应在训练前告知教练。

## 器械使用

1. 使用杠铃深蹲架和卧推架时，必须安装安全限位杆。
2. 使用跑步机时应先夹好急停绳，再逐步提高速度。
3. 器械使用完毕后，将重量调回空载并擦拭接触部位。
4. 发现钢丝绳破损、螺栓松动或异响时，立即停止使用并通知前台。

## 受伤和突发情况

1. 发现会员摔倒、胸痛、呼吸困难或失去意识时，立即停止周围训练并呼叫当班教练。
2. 当班教练负责拨打 120，并安排一名员工到门口引导急救人员。
3. 未经授权不得移动疑似脊柱受伤人员，不得擅自提供药物。
4. 事故处理结束后，值班员工应在当日填写《训练区事件记录表》，记录时间、地点、人员和处理经过。
