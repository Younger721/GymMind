# 星河健身房会员服务规则

## 会员卡使用

1. 会员卡仅限本人使用，首次到店需要出示注册手机号或有效证件。
2. 月卡有效期为开卡日起 30 天，季卡有效期为 90 天，年卡有效期为 365 天。
3. 会员可以在营业时间内使用有氧区、力量区和拉伸区。团体课程需要单独预约。
4. 会员卡过期后不能进入训练区，也不能继续预约课程。

## 请假与延期

1. 月卡会员每个自然月最多可申请 3 天冻结，季卡和年卡会员每个自然月最多可申请 7 天冻结。
2. 冻结申请需要在前台提交，补交材料不晚于冻结开始日前一天。
3. 课程报名后临时不能参加，应在开课前 2 小时取消，否则记一次爽约。

## 退款规则

未使用的会员卡可以在购买后 7 天内申请退款。已经使用过的会员卡不支持直接退款，特殊情况由门店管理员审批。
