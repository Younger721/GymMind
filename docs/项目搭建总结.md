## 🏗️ 架构亮点

### 1. 双重索引架构（RAG 核心）
```
文档 → 解析 → 分块 → Embedding
         ↓
    双写到两个索引
         ↓
┌──────────────┬──────────────┐
│ Milvus       │ Elasticsearch│
│ - 语义检索   │ - 关键词匹配 │
│ - 向量相似度 │ - 中文分词   │
└──────────────┴──────────────┘
         ↓
    混合召回 + RRF 融合
         ↓
      最终结果
```

### 2. 后端分层架构
```
Controller → Service → Repository → Database
    ↓
  DTO ←→ Entity
    ↓
Security Filter (JWT)
```

### 3. 前端状态管理
```
View → Pinia Store → API Client → Backend
  ↓
Router Guard (认证检查)
```

### 4. 安全机制
- ✅ JWT 令牌认证
- ✅ Spring Security 配置
- ✅ 密码 BCrypt 加密
- ✅ 请求/响应拦截器
- ✅ CORS 跨域配置
- ✅ 用户数据隔离（userId 过滤）

## 🚀 快速启动

### 最快 3 步启动
```bash
# 1. 配置 .env（MySQL 密码、JWT 密钥、AI API Key）
# 2. 启动基础设施
start-infrastructure.bat

# 3a. 启动后端（新终端）
cd backend && mvn spring-boot:run

# 3b. 启动前端（新终端）
cd frontend && npm install && npm run dev
```
