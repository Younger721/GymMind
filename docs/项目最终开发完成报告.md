## 🚀 部署与启动

### 环境要求
- Java 17+
- Node.js 18+
- Maven 3.8+
- Docker & Docker Compose
- MySQL 8.0

### 快速启动

```bash
# 1. 配置环境变量
cp .env.example .env
# 编辑.env文件：
# - MYSQL_PASSWORD (MySQL密码)
# - JWT_SECRET (JWT密钥)
# - AI_API_KEY (AI API密钥)

# 2. 创建数据库
mysql -u root -p
CREATE DATABASE gymmind CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 3. 启动基础设施
start-infrastructure.bat  # Windows
./start-infrastructure.sh # Linux/Mac

# 4. 启动后端
cd backend
mvn clean install
mvn spring-boot:run

# 5. 启动前端
cd frontend
npm install
npm run dev

# 6. 访问应用
http://localhost:5173
```
