# 全角色训练区安全须知（评测语料）

> 平台级公开安全提示，教练与会员均应可见。

## 通用要求

**EVAL-PLAT-SAFE-001**：进入训练区须穿包脚运动鞋，禁止拖鞋、赤足或使用露趾鞋。

**EVAL-PLAT-SAFE-002**：自由重量区举放杠铃时必须使用卡扣；卸片时应先通知周围会员离开落点。

## 紧急情况

**EVAL-PLAT-SAFE-003**：若会员出现胸痛、眩晕或疑似中暑，任何在场人员应第一时间按下墙边红色报警钮，并呼叫前台 **119 联动流程**（代码 **EVAL-PLAT-SAFE-911**）。

## 清洁与消毒

训练结束后对接触面进行擦拭；平台标准消毒液配比为 1:100，详见物料包标签 **EVAL-PLAT-SAFE-CLEAN**。
