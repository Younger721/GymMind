# 鹈鹕骑自行车 SVG 动画设计

## 目标

创建一个可以直接双击打开的单文件 HTML，用内联 SVG 绘制一只鹈鹕骑自行车的 2D 动画，并用轻量交互表达“判断 AI 是否降智”的趣味主题。

## 视觉与布局

- 明快童趣风格：青绿色天空、暖黄色鹈鹕、深色粗描边、珊瑚色点缀。
- 画布采用宽屏比例并在窄屏下自适应，主体保持稳定尺寸和清晰层次。
- 场景包含天空、云朵、远山、海岸线、公路、鹈鹕和自行车。
- 右上角显示 AI 状态徽章，状态文案在“思考中 / 状态良好 / 小心降智”之间切换。

## 动画与交互

- SVG/CSS 动画：车轮旋转、脚蹬联动、鹈鹕身体轻微起伏、云朵与路面移动。
- “暂停动画”按钮切换全部运动元素的播放状态，并同步按钮文案。
- “换个 AI 状态”按钮循环切换状态文案、颜色和进度条。
- JavaScript 仅处理交互状态，不承担 SVG 绘制。

## 文件范围

- 新增 `output/pelican-bike.html`，包含全部 HTML、CSS、SVG 和 JavaScript。
- 不修改现有业务代码和当前工作区内其他未提交改动。

## 验收标准

1. 直接打开 HTML 可看到非空 SVG 场景和动画。
2. 暂停按钮可以停止并恢复动画。
3. AI 状态按钮至少循环三种状态，徽章视觉随状态变化。
4. 页面在桌面宽度和窄屏宽度下无明显溢出或遮挡。
