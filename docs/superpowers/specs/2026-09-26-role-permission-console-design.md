# 角色权限配置控制台设计

## 目标

为平台管理员提供按角色配置页面访问和操作权限的控制台，复用现有 `sys_role`、`sys_permission`、`sys_role_permission` 数据模型。前端负责菜单、路由和按钮体验，后端继续以 Spring Security/应用服务权限校验作为最终边界。

## 范围

- 读取角色和权限目录，展示角色权限矩阵。
- 保存指定角色的权限集合，采用整体替换，保证结果可预测。
- 平台管理员可配置健身房管理员、教练、会员；平台管理员自身权限固定为全部权限。
- 配置变更在下一次登录或刷新身份信息后生效。
- 暂不支持单个用户例外授权、租户级自定义权限和权限目录编辑。

## 后端

新增角色权限查询/更新用例与 API：读取角色列表、权限目录及每个角色当前权限；更新时校验操作者为平台管理员，禁止修改平台管理员角色，校验权限编码来自系统目录，并事务性替换 `sys_role_permission` 关联。

## 前端

新增权限管理页面和 API 客户端。页面按角色选择器、权限分组和复选框矩阵展示；保存按钮只对平台管理员开放，成功后提示重新登录或刷新权限。菜单加入平台权限管理入口。

## 安全与错误处理

所有 API 在 controller 和 application service 双重校验；非法角色、未知权限、试图修改平台管理员权限统一返回 403/400。保存失败保留当前勾选状态并显示错误。

## 验证

覆盖服务层的权限替换、平台管理员保护、未知权限拒绝测试；运行后端 Maven 测试/编译和前端生产构建。
