---

### ✅ 阶段2：个人知识库与文档处理（95%）

**文档上传与存储**
- 文件类型验证（PDF、TXT，最大50MB）
- MinIO 对象存储集成
- 文档元数据存储（MySQL）
- 按用户分区存储（user_id/文件名）

**文档处理流水线**
- PDF 解析（PDFBox）
- TXT 解析（UTF-8）
- 文本清洗和标准化
- 智能分块（滑动窗口512字符，overlap 50）
- 句子边界检测（中英文标点）
- 词边界检测

**双重索引架构** ⭐ 核心创新点
- **Milvus 向量存储**
  - Collection 自动创建
  - HNSW 索引（M=16, efConstruction=256）
  - COSINE 相似度度量
  - 字段：user_id, document_id, chunk_index, embedding(1536维)
  
- **Elasticsearch 全文存储**
  - Index 自动创建
  - smartcn 中文分词器
  - 字段：user_id, document_id, document_name, chunk_text, category, source_type
  
- **同步双写机制**
  - 每个chunk同时写入Milvus和ES
  - 保存chunk元数据到MySQL
  - 记录Milvus ID和ES ID

**状态管理**
- PENDING → PROCESSING → SUCCESS/FAILED
- 异步处理（Spring @Async）
- 失败原因记录
- 重试机制

**前端界面**
- 文档上传对话框（拖拽上传）
- 文档列表表格（分页、过滤）
- 统计卡片（总数、处理中、成功、失败）
- 状态标签显示
- 失败重试按钮
- 自动刷新（10秒）

---

### ✅ 阶段3：RAG智能问答（90%）

**混合检索服务** ⭐ 论文核心
- **向量召回**（Milvus）
  - 查询文本生成embedding
  - Top-K向量检索（默认10条）
  - 按userId过滤
  - COSINE相似度排序

- **关键词召回**（Elasticsearch）
  - 全文匹配查询
  - Top-K关键词检索（默认10条）
  - 按userId过滤
  - BM25评分

- **RRF融合排序** ⭐
  - Reciprocal Rank Fusion算法
  - k=60常数
  - 综合两种检索结果
  - 返回Top-K融合结果（默认5条）

**RAG问答服务**
- 用户画像上下文
  - 身高、体重、健身目标
  - 经验水平、训练频率

- 知识库上下文

  - 相关性评分

- AI生成
  - OpenAI兼容API（DeepSeek/Qwen）
  - 系统提示词构建
  - 对话历史管理
  - 来源引用生成

- 响应指标
  - Token使用统计
  - 响应时间
  - 是否有可靠来源标识

**前端聊天界面**
- 消息列表（用户/助手）
- Markdown渲染
- 来源引用展示
- 输入区域（支持Enter发送）
- 打字动画效果
- 建议问题标签
- 清空聊天按钮

## 核心技术亮点

### 1. 双重索引混合检索架构 ⭐⭐⭐
这是本项目最大的创新点和技术亮点：
- **Milvus向量检索**: 捕捉语义相似度，理解用户意图
- **Elasticsearch全文检索**: 精确匹配关键词，确保准确性
- **RRF融合算法**: 综合两种检索优势，提升召回率和准确率
- **用户数据隔离**: 所有检索都严格按userId过滤

### 2. 异步处理流水线
- 上传立即返回，后台异步处理
- 不阻塞用户操作
- 状态机管理（PENDING/PROCESSING/SUCCESS/FAILED）
- 失败重试机制

### 3. 智能文本分块
- 滑动窗口（512字符，overlap 50）
- 句子边界检测（避免语义截断）
- 词边界检测（避免单词截断）

### 4. 个性化RAG
- 结合用户画像（身体数据、健身目标、经验水平）
- 提供个性化健身建议
- 明确区分知识库来源和通用建议

### 5. 完整的前后端分离架构
- RESTful API设计
- JWT无状态认证
- TypeScript类型安全
- 响应式UI

### 1. 配置环境变量
```bash
cp .env.example .env
# 编辑.env文件，填入实际配置
```

### 2. 创建MySQL数据库
```sql
CREATE DATABASE gymmind CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 3. 启动基础设施
```bash
# Windows
start-infrastructure.bat

# Linux/Mac
./start-infrastructure.sh
```

### 4. 启动后端
```bash
cd backend
mvn clean install
mvn spring-boot:run
```

### 5. 启动前端
```bash
cd frontend
npm install
npm run dev
```

### 6. 访问应用
- 前端: http://localhost:5173
- 后端: http://localhost:8080/api
