## 架构设计

### 后端分层架构
```
Controller → Service → Repository → Database
    ↓
  DTO (请求/响应)
    ↓
  Entity (JPA)
```

### 前端架构
```
View → Store (Pinia) → API Client (Axios) → Backend
  ↓
Router (导航守卫)
```

### 双重索引架构（RAG 核心）
```
文档上传 → 解析 → 分块 → Embedding
    ↓
   双写
    ↓
┌─────────────────┬─────────────────┐
│  Milvus (向量)   │   ES (全文)      │
│  - 语义检索      │   - 关键词匹配   │
│  - HNSW 索引    │   - 中文分词     │
│  - COSINE 度量  │   - 元数据过滤   │
└─────────────────┴─────────────────┘
    ↓           ↓
    向量召回   关键词召回
         ↓
    RRF 融合排序
         ↓
      最终结果
```

## 项目启动步骤

### 1. 配置环境变量
```bash
# 编辑 .env 文件，配置：
# - MYSQL_PASSWORD（本地 MySQL 密码）
# - JWT_SECRET（JWT 密钥）
# - AI_API_KEY（AI API 密钥）
```

### 2. 创建数据库
```sql
CREATE DATABASE gymmind CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 3. 启动基础设施
```bash
# Windows
start-infrastructure.bat

# Linux/Mac
./start-infrastructure.sh
```

### 4. 启动后端
```bash
cd backend
mvn clean install
mvn spring-boot:run
```

### 5. 启动前端
```bash
cd frontend
npm install
npm run dev
```

### 6. 访问应用
- 前端: http://localhost:5173
- 后端: http://localhost:8080/api

## 注意事项

1. **环境变量配置**: 首次启动前必须配置 `.env` 文件
2. **MySQL 密码**: 需要本地 MySQL 的正确密码
3. **JWT Secret**: 生产环境必须更换为强密钥
4. **AI API Key**: RAG 功能需要配置 AI API 密钥
5. **端口占用**: 确保 8080、5173、9200、19530 等端口未被占用

## 项目特色

1. **双重索引架构**: Milvus (向量) + Elasticsearch (全文) 混合检索
2. **严格的用户隔离**: 所有查询都带 userId 过滤
3. **现代化技术栈**: Spring Boot 3 + Vue 3 + TypeScript
4. **完整的认证体系**: JWT + Spring Security
5. **Docker 一键启动**: 所有基础设施都容器化
6. **类型安全**: 后端 Java 泛型 + 前端 TypeScript
