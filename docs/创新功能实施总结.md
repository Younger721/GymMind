### 3. WebSocket 实时推送（已完成 ✅）

**后端实现**：
- ✅ `WebSocketConfig` - Spring WebSocket 配置
  - 启用 STOMP 协议
  - 配置消息代理（/topic, /queue）
  - 允许跨域连接
  
- ✅ `WebSocketService` - 推送服务
  - `sendToUser()` - 发送给特定用户
  - `sendDocumentProgress()` - 文档处理进度推送
  - `sendAiStream()` - AI 流式响应推送
  - `sendNotification()` - 实时通知
  - `broadcastToAll()` - 全局广播
  
- ✅ `WebSocketMessage` DTO
  - 支持三种消息类型：
    - DOCUMENT_PROGRESS：文档上传/处理进度
    - AI_STREAM：AI 对话流式响应（打字机效果）
    - NOTIFICATION：系统通知

**使用场景**：
- 📄 文档上传后实时显示：解析中 → 分块中 → Embedding 生成中 → 索引中 → 完成
- 💬 AI 对话逐字显示，提升体验流畅度
- 🔔 实时通知：好友动态、挑战邀请、计划提醒

**核心价值**：
- ⚡ 用户无需刷新页面即可看到实时更新
- 🎭 AI 对话的打字机效果更有沉浸感
- 📡 为后续社交功能打下基础

### 9. AR 姿态识别与纠错

**前端集成**（MediaPipe Pose）：
```bash
npm install @mediapipe/pose
```

```typescript
// composables/usePoseDetection.ts
import { Pose } from '@mediapipe/pose'

export function usePoseDetection() {
  const pose = new Pose({
    locateFile: (file) => {
      return `https://cdn.jsdelivr.net/npm/@mediapipe/pose/${file}`
    }
  })
  
  pose.setOptions({
    modelComplexity: 1,
    smoothLandmarks: true,
    enableSegmentation: false,
    minDetectionConfidence: 0.5,
    minTrackingConfidence: 0.5
  })
  
  return { pose, landmarks }
}
```

**实施步骤**：
1. 前端实时捕获摄像头画面
2. MediaPipe 检测关节点
3. 发送关节点数据到后端 → 对比标准动作 → 返回纠错建议
4. 前端显示 AR 覆盖层（绿色=正确，红色=错误）

**预期效果**：
- 用户做深蹲 → 实时检测膝盖是否超过脚尖 → 语音提示"膝盖后移"

CREATE TABLE workout_plans (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,

    goal VARCHAR(50) NOT NULL,

    exercises TEXT,
    notes VARCHAR(500),
    is_rest_day BOOLEAN NOT NULL,

    INDEX idx_plan_id (plan_id)
);
